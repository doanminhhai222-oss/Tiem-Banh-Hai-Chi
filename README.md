# Hải Chi Bakery

Web tĩnh (HTML/CSS/JS thuần) cho tiệm bánh Hải Chi: giới thiệu, menu bánh & thức uống, giỏ hàng (topping/ghi chú), tích điểm & voucher, hạng VIP, đánh giá, hỏi đáp.

Chạy: mở `index.html` hoặc `python3 -m http.server`. Dữ liệu menu, địa chỉ, hạng thành viên sửa trong `js/data.js`.
Dữ liệu giỏ hàng/tài khoản/đánh giá lưu trong `localStorage` (bản demo, chưa có máy chủ).
